# Deep-Learning-Image-Classification-Portfolio

This repository showcases three fundamental Convolutional Neural Network (CNN) projects, progressing in complexity from simple digits to complex color images.

## 1. Handwritten Digit Recognition (MNIST)
* **Goal:** Classify grayscale digits (0-9).
* **Complexity:** Low. Serves as a baseline CNN implementation.

## 2. Fashion Item Classification (Fashion-MNIST)
* **Goal:** Identify 10 clothing types (shirts, shoes, etc.).
* **Complexity:** Moderate. Requires more robust feature extraction than MNIST.

## 3. CIFAR-10 Image Classification
* **Goal:** Classify 10 real-world objects (cats, cars, planes) in color.
* **Complexity:** High. Utilizes a deeper CNN with Batch Normalization to handle 3-channel RGB images and subtle features.
